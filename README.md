# Satisfactory Modeler Database for mods

Growing database for [Satisfactory Modeler](https://satisfactorymodeler.itch.io/satisfactorymodeler) that includes recipes from mods.

Base game recipes that are modified by mods are included as extra prefixed recipes. In general, all recipes from mods are prefixed with the mod name.

## Usage

- Install a separate installation of Satisfactory Modeler to not mess up your existing one.
- Go to the [releases](https://github.com/QuingKhaos/satisfactory-modeler-pm/releases) page.
- Download the latest database archive.
- Extract the database archive into your new Satisfactory Modeler installation, overwriting existing files.
